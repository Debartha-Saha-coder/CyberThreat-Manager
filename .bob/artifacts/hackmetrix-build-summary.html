Quick Start

# 1. Configure environment
cp .env.example .env && edit .env

# 2. Install backend
cd backend && pip install -r requirements.txt

# 3. Run backend
uvicorn app.main:app --reload --port 8000

# 4. Run frontend (requires Node.js 20+)
cd frontend && npm install && npm run dev

# 5. Run tests
pytest tests/ -v
⚠ Node.js 20+ is required for the frontend. Install from nodejs.org before running npm commands. The backend runs independently without Node.js.
